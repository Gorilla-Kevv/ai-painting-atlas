01Stable Diffusion 本地运行

SD 是开源潜扩散模型，本地运行需 NVIDIA 显卡与模型权重文件。

硬件要求

  • 入门：GTX 1060 6GB 可跑 SD 1.5（512 分辨率）
  • 主流：RTX 3060 12GB / 4060 8GB，可玩 SDXL
  • 进阶：RTX 4080/4090 24GB+，跑 Flux/SD3 无压力
  • 内存 ≥16GB，存储预留 50GB+（模型与生成结果）

配置步骤

  1. 准备 NVIDIA 显卡，安装最新显卡驱动与 CUDA
  2. 从 Hugging Face stabilityai 下载基础模型（如 v1-5-pruned-emaonly.safetensors）
  3. 把模型放入工具的 models/Stable-diffusion 目录
  4. 通过 WebUI 或 ComfyUI 加载并出图（见下方对应教程）
参考来源
Hugging Face · stabilityai 模型库 Stability AI 官网

02WebUI (AUTOMATIC1111) 安装

SD 最经典图形界面，官方推荐通过 git 克隆 + Python 环境安装。

环境准备

  • 安装 Python 3.10.6（64 位，勾选 Add to PATH）
  • 安装 Git（git-scm.com）
  • NVIDIA 显卡 + 最新驱动

配置步骤

  1. 克隆仓库
    2. git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
  2. 进入目录，编辑 webui-user.bat，按需设置 COMMANDLINE_ARGS（如 --xformers --medvram 低显存优化）
  3. 双击 webui-user.bat，首次运行会自动下载依赖（耗时较长）
  4. 把 SD 模型放入 models/Stable-diffusion，VAE 放入 models/VAE
  5. 浏览器打开 http://127.0.0.1:7860 即可使用
参考来源
GitHub · AUTOMATIC1111/stable-diffusion-webui Wiki · Install and Run on NVidia GPUs

03ComfyUI 安装配置

节点式 SD 工作流工具，推荐用便携版 + ComfyUI Manager 扩展管理器。

配置步骤

  1. 从 GitHub Releases 下载 ComfyUI 便携版（含 Python 与依赖），解压到任意目录
  2. 把 SD 模型放入 ComfyUI/models/checkpoints，VAE 放 models/vae，LoRA 放 models/loras
  3. 安装 ComfyUI Manager（节点应用商店）：进入 custom_nodes 目录克隆
    4. cd ComfyUI/custom_nodes git clone https://github.com/ltdrdata/ComfyUI-Manager.git
  4. 运行 run_nvidia_gpu.bat（N 卡）启动
  5. 浏览器打开 http://127.0.0.1:8188，加载默认工作流出图
  6. 通过 Manager 菜单可一键安装/更新自定义节点与模型
参考来源
GitHub · comfyanonymous/ComfyUI GitHub · ComfyUI-Manager（官方扩展管理器） ComfyUI 官方文档 docs.comfy.org

04秋叶整合包（绘世启动器）

民间打包的开箱即用 SD 环境，国内入门事实标准，3 分钟即可启动。

配置步骤

  1. 从 B 站 up 主「秋叶」官方渠道下载整合包（如 sd-webui-aki），支持 SD3.5/Flux
  2. 先安装「启动器运行依赖」（VC++ 运行库等，必装步骤）
  3. 解压整合包到无中文无空格路径的目录
  4. 双击 A启动器.exe（绘世启动器），首次会自动校验环境
  5. 在启动器「一键启动」处点击，自动拉起 WebUI，浏览器打开对应端口
  6. 启动器内可切换模型版本、管理插件、汉化界面、调整显存优化参数

常见问题

  • 提示「没有 xformers」：低显存可关闭，或用 --xformers 参数安装替代
  • 首次启动慢：自动下载程序文件，耐心等待

05LoRA 训练（Kohya_ss）

用 Kohya_ss 图形工具训练自己的 LoRA，改画风/角色，门槛比想象低。

硬件要求

  • 显存 8GB 起步（12GB+ 更稳），SD 1.5 训练最友好
  • 训练数据集：15–30 张同主体/同画风高清图

配置步骤

  1. 安装 Kohya_ss（github.com/bmaltais/kohya_ss），按 README 安装 Python 环境与依赖
  2. 准备数据集：图片放 img 目录，按 数字_触发词 命名子文件夹（如 20_mychar）
  3. 为每张图编写描述文件（.txt），描述内容与触发词
  4. 启动 Kohya_ss GUI，切换到 Dreambooth LoRA 标签
  5. 设置参数：基础模型、训练步数（数据量×10–20）、batch size、学习率（常用 1e-4）
  6. 点击训练，完成后 LoRA 文件输出到 output 目录（几十~几百 MB）
  7. 把 LoRA 放入 WebUI/ComfyUI 的 models/Lora，提示词用 <lora:文件名:0.8> 触发
参考来源

06云 GPU 平台使用

没有显卡也能跑 SD/ComfyUI，国内推荐 AutoDL，国外 RunPod/Colab。

配置步骤（以 AutoDL 为例）

  1. 注册 AutoDL（autodl.com），充值算力
  2. 选择 GPU 实例（如 RTX 3090/4090），选择预置镜像「Stable Diffusion / ComfyUI」
  3. 开机后通过控制台提供的链接访问 WebUI/ComfyUI（自动配置端口）
  4. 模型可通过 AutoDL 的模型市场一键挂载，或从 Hugging Face/Civitai 下载
  5. 关机不计费（只收存储费），按需开关节省成本

其他平台

  • RunPod：按量租 GPU，预置 SD/ComfyUI 模板
  • Google Colab：免费/付费笔记本，可跑 SD（资源有限）
  • Banana/Replicate：把 SD 部署为 API，面向开发者
参考来源
AutoDL 官网（国内 GPU 租赁） RunPod 官网 Google Colab
